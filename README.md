# Support Ticket Classification System

## Objective
Build a machine learning system that automatically classifies customer support tickets into categories and assists in prioritizing support requests.

## Tools Used
- Python
- Pandas
- NLTK
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Features
- Text preprocessing and cleaning
- Tokenization and stopword removal
- TF-IDF feature extraction
- Ticket category classification
- Priority analysis
- Model evaluation using accuracy and classification metrics
- Confusion Matrix visualization

## Dataset
Customer Support Tickets Dataset

## Methodology
1. Loaded support ticket data.
2. Cleaned and preprocessed ticket descriptions.
3. Converted text into numerical features using TF-IDF.
4. Split data into training and testing sets.
5. Trained a Multinomial Naive Bayes classifier.
6. Evaluated model performance.
7. Predicted categories for new support tickets.

## Results
Successfully classified customer support tickets into different categories using NLP and Machine Learning techniques with measurable accuracy.
